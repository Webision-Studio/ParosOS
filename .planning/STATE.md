## 🎯 Strategic Decisions
- **Competitor Target:** Petpooja (unbundling the complex, expensive, hardware-heavy 80% into an agile 20% that delivers 80% of value).
- **Core Value Pillars:**
  1. Instant touch-friendly table and counter billing.
  2. Live Digital Kitchen Display System (paperless, real-time KOT).
  3. Integrated CRM with customer memory and 1-click WhatsApp Digital Receipts.
  4. Real-time owner dashboard with day-end Z-reports.
- **Architecture Choice:** Next.js 15 (App Router), TypeScript, Tailwind CSS, Prisma ORM with SQLite for frictionless local setup & PostgreSQL compatibility.
